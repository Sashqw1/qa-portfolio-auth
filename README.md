# QA-портфолио: тестирование веб-сервиса ROBOCALC

Полный цикл тестирования одного продукта: от тест-плана до отчётов о дефектах
и автотестов. Все находки воспроизводимы — стенд открыт, ссылки рабочие.

**Объект тестирования:** [ROBOCALC](https://sashqw1.github.io/Sashqw1-robocalc/) —
веб-сервис подбора роботизированных решений и расчёта экономического эффекта
для склада, аэропорта и медицинского учреждения. Пользователь проходит визард
из восьми шагов и получает подбор техники, расчёт CAPEX/OPEX/TCO и сравнение
сценариев финансирования.

## Подход

Проверки строились не вокруг кнопок, а вокруг вопроса «какому числу пользователь
в итоге поверит». Поэтому основное внимание — границам: пустой состав
оборудования, нулевая стоимость персонала, сценарий без вложений, отсутствие
окупаемости. Четыре из семи дефектов нашлись именно там, а не в основном сценарии,
где всё заполнено корректно.

Техники тест-дизайна: классы эквивалентности и граничные значения для числовых
полей, таблица решений для доступа по ролям, переходы состояний для статуса
проекта, исследовательское тестирование для поиска аномалий.
