# Чек-лист: интерфейс, темы и разрешения

Проверка выполнена снимками экрана в Microsoft Edge 141 (headless) по 13 ключевым
адресам стенда в двух разрешениях. Скриншоты — в каталоге [screenshots/](../screenshots/).

## Разрешение 1366×768 — целевое по нефункциональным требованиям

| № | Экран | Проверка | Результат |
|---|---|---|---|
| 1.1 | Главная | Первый экран читается без прокрутки, призыв к действию виден | + |
| 1.2 | Каталог | Таблица помещается по ширине, фильтры доступны | + |
| 1.3 | Мои проекты | Список и панель фильтров не перекрываются | + |
| 1.4 | Визард, шаг 2 | Форма, боковая навигация разделов и подсказка помещаются в три колонки | + |
| 1.5 | Визард, шаг 3 | Карточки подбора и причины решения видны целиком | + |
| 1.6 | Визард, шаг 5 | Условия расчёта и результат видны одновременно | + |
| 1.7 | Визард, шаг 7 | План объекта занимает рабочую область, панель свойств не обрезана | + |
| 1.8 | Дашборд | KPI, график денежного потока и структура затрат помещаются | + |
| 1.9 | Отчёт | Печатная форма без горизонтальной прокрутки | + |
| 1.10 | Админка | Таблица каталога помещается, действия доступны | + |
| 1.11 | Все экраны | Нижняя панель визарда не перекрывает содержимое | + |

## Темы оформления

Снимками экрана не проверялось: headless-режим не позволяет эмулировать системную
схему. Пункты проверены по реализации (`widgets/AppHeader.tsx`, `shared/styles/tokens.css`).

| № | Проверка | Способ | Результат |
|---|---|---|---|
| 3.1 | Переключатель темы в шапке задаёт атрибут `data-theme` | код | + |
| 3.2 | Тёмная тема определена и переопределяет токены цвета | код | + |
| 3.3 | Учитывается системная схема `prefers-color-scheme: dark` | код | + |
| 3.4 | Выбранная тема сохраняется в localStorage между сессиями | код | + |
| 3.5 | Контраст текста в тёмной теме по WCAG AA | — | не выполнено, требует интерактивной сессии |
