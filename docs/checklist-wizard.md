# Чек-лист: визард расчёта, шаги 1–8

Стенд: https://sashqw1.github.io/Sashqw1-robocalc/
Роль переключается селектом в шапке либо параметром адреса `?as=user`, `?as=admin`.

**Результат:** + работает · − дефект (ссылка на отчёт) · n/a вне объёма
**Способ:** `UI` — проход по стенду со снимком экрана · `авто` — автотест Vitest ·
`код` — проверка реализации в исходниках
